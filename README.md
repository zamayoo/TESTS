# TESTS

Незалежна навчальна платформа з чотирма напрямами:

- аудит і державний фінансовий контроль;
- оперативні та аналітичні здібності — 30 завдань;
- публічні закупівлі — 210 запитань, 50 випадкових на іспиті, 60 хвилин, прохідний результат 30/50;
- логіка та когнітивні здібності — 38 оригінальних завдань TESTS, 20 хвилин; результат не є стандартизованим показником IQ.

Кожен напрям має окрему базу, навчальний прогрес, правила іспиту та формулювання навчального сертифіката. Сертифікати TESTS не є офіційними документами державних органів і не підтверджують кваліфікацію.

## Локальний запуск

```powershell
python -m venv .runtime
.\.runtime\Scripts\python.exe -m pip install -r server\requirements.txt
$env:DATA_PATH="$PWD\local-data\tests.db"
$env:COOKIE_SECURE="false"
$env:PUBLIC_URL="http://127.0.0.1:8000"
.\.runtime\Scripts\python.exe -m uvicorn server.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Секреты в репозитории не требуются. Для электронной почты, Google OAuth и серверного голоса используются только переменные окружения, перечисленные в `compose.yaml`.

## Проверки

```powershell
node --check dist\app.js
node --check dist\account.js
.\.runtime\Scripts\python.exe -m unittest discover -s tests -v
```

## Открытые источники

- Публичные закупки: приказ Министерства экономики Украины № 873-21. Вопросы и подчёркнутые правильные ответы перенесены без обращения к закрытой базе старого сайта.
- Аналитические способности: открытый пример и ключ Службы внешней разведки Украины. Изображения заданий сохранены локально, чтобы курс не зависел от старого сайта.

- Логіка та IQ: публічний сценарій TestLibrary використано лише як орієнтир для формату (38 завдань, 20 хвилин). Питання, ключі, алгоритм оцінювання та платний звіт TestLibrary не копіювалися; усі завдання курсу створені для TESTS.

Старый сайт использовался только для чтения и сравнения пользовательского сценария. Его серверный код, аккаунты и база данных не копировались.
